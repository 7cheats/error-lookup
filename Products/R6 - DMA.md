# **7Cheats R6 DMA Error Lookup**

## **ESP Issues**

### ESP Lagging or Slow Rotation Updates

* Ask them for the set **delay of update speed** within the cheat

  * ➤ **Skeleton Update Delay** -> 1 (lower value = less lag = worse performance)
  * ➤ **Rotation Update Delay** -> 1 (lower value = less lag = worse performance)

---

### ESP Showing Late

* To ensure that everything is set up correctly, let them load into the shooting range first.
* In rare cases, the initial load can take longer but speeds up afterwards.

  * ➤ Have them **try different V-Sync types** (Auto should do this automatically)
  * ➤ Ask for **DMA Card Type and read speed** by using **our speed test** tool. (Not Lonedma!)

  * Using more features increases the amount of resources needed from the card!
  * Longer loading times can also occur due to weak secondary computers.

---

### Players Missing and Not Showing

* Currently, in rare cases, some enemies may be missing.

  * ➤ Have them use **Extensive Bruteforce** within the cheat settings.

---

### ESP Disappears Mid-Round and Jumps Back to Finding Players

* This is a typical memory issue on the main PC.

  * ➤ Have them disable memory compression on the main PC and restart. (Run pwsh as admin and type `Disable-MMAgent -mc`)
  * Memory compression tends to reactivate somehow.

---

### Desktop Is Visible and Not Hidden

* Transparency is enabled within the cheat.

  * ➤ Have them disable it within the settings section of the cheat.

---

## **Aimbot & Makcu Issues**

### Makcu Won't Connect

* Ensure that the Makcu is connected and receives commands from the Makcu App.

  * ➤ Ensure the cheat is closed, have them open the Makcu app and type km.move(100,0).
  * The mouse should move and the Makcu received a signal; now the user can close the Makcu app and reopen the cheat.
  * The connection should **succeed** now.
  * *In rare cases, the firmware could be corrupted. In this case, simply reflash the firmware.*

---

### Enabling Aimbot Shows Windows Build Error

* This error occurs due to an issue with Windows on the main PC.

  * ➤ Have them update their Windows on the main PC. In case there is no update available, any optional update should suffice.

---

### Jittery Aimbot

* Increase frameskip (makes it more snappy)

---

## To Ensure a Clean Setup of the Cheat, Follow These Steps:

1. Open the game and load into the main menu.
2. Open the loader and start the cheat.
3. Wait until **Setup complete** appears.
4. Load into the shooting range and wait for the ESP to appear.

* If the ESP shows and nothing is bugged, the user is good to go.
